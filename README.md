# Jielun Zhong - Academic Portfolio

Personal academic website for Jielun Zhong, built as a static GitHub Pages site.

## Local preview

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173/` in a browser.

## Publish

Create a public GitHub repository named `zhongjielun2023-droid.github.io`, push the `main` branch, then enable GitHub Pages with **Deploy from a branch** using `main` and `/ (root)`.

The published site will be available at `https://zhongjielun2023-droid.github.io/`.

## Design references

- [Leigang Qu](https://leigang-qu.github.io/): restrained academic structure and clear publication hierarchy.
- [Jiajun Wu](https://jiajunwu.com/): direct identity, contact, and research navigation.
- [Taesung Park](https://taesung.me/): image-led research browsing and concise descriptions.
- [Jon Barron](https://jonbarron.info/): compact publication rows and easy-to-scan links.
- [Matthew Tancik](https://www.matthewtancik.com/): stronger visual authorship and project-led presentation.
